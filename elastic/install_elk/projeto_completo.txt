# Instalação do cluster ELK (Elasticsearch + Kibana + Fleet): 21 servidores, RHEL 9

Projeto Ansible para o AAP. Versão fixada em **9.5.5** (`group_vars/all.yml`).

> **Aviso:** escrito e revisado offline (sintaxe, templates, lógica do plano de discos), mas **ainda não executado em servidores reais**.
> Comece pela ação `precheck`, que não altera nada.

## 1. Estrutura

```
inventory.yml        só os servidores e os grupos
group_vars/          all.yml (acao, versão, F5, Fleet...) e um arquivo por grupo (papéis, heap e discos de cada tipo de servidor)
vault.yml.example    modelo dos 7 segredos (crie o vault.yml a partir dele e criptografe)
collections/requirements.yml     community.general (lvg, lvol, filesystem) e ansible.posix (mount)
site.yml             o único playbook: chama os roles, cada um com um "when" na variável acao

roles/precheck/      verificações antes de instalar + plano de discos (somente leitura)
roles/infra/         discos (LVM + XFS) e sistema (kernel, swap, THP, limites)
roles/instalacao/    tasks/main.yml dividido em FASES · handlers/main.yml · templates/
roles/validacao/     conferência final (somente leitura)
```

## 2. Acesso

O exec node entra nos 21 servidores **como root**, com a chave da credencial Machine do Job Template (essa chave precisa estar autorizada
no root dos servidores). Se o exec node **não** alcança os servidores direto, preencha `bastion_host` em `group_vars/all.yml`: o SSH
passa a atravessar o bastion como túnel (o `sshd` do bastion precisa permitir `AllowTcpForwarding`). Vazio = conexão direta.

## 3. Antes de começar

1. Revise `inventory.yml` e `group_vars/` (papéis, heap, discos, nomes do F5, bastion).
2. Segredos: copie `vault.yml.example` para `vault.yml`, gere os valores (`openssl rand -hex 24`) e criptografe com `ansible-vault encrypt vault.yml`.
   **Nunca** versione o `vault.yml` aberto. As 3 chaves do Kibana e o nome do cluster **não podem mudar depois** de instalado.
3. AAP: Inventory com fonte no projeto (`inventory.yml`); Job Template com `site.yml`, a credencial Machine (root) e a credencial *Vault*.
   O Execution Environment precisa das collections de `collections/requirements.yml`.
4. Survey: pergunta `acao` (escolha única: `precheck`, `instalar`, `validar`). Opcionais: `es_bootstrap_allowed` e `componentes`.

## 4. O que executar: a variável `acao`

| `acao` | Roles | O que faz |
|--------|-------|-----------|
| `precheck` | `precheck` | versão, segredos, NTP, DNS, repositório, internet, portas e **plano de discos**. Não altera nada |
| `instalar` | `precheck` + `infra` + `instalacao` | pre-check, discos, sistema e os `componentes` |
| `validar` | `validacao` | discos montados, cluster *green*, 16 nós, serviços, Kibana, Fleet. Não altera nada |

`componentes` (padrão `[elasticsearch, kibana, fleet]`) escolhe o que a ação `instalar` executa:
`elasticsearch` (pacote, certificados, configuração, formação do cluster com os 3 masters e depois os demais nós, um por vez, senhas),
`kibana` (um por vez) e `fleet` (configura o Fleet no Kibana e instala o Fleet Server nos 2 `integration`).

```bash
ansible-playbook site.yml                                                   # precheck (so leitura)
ansible-playbook site.yml -e acao=instalar -e es_bootstrap_allowed=true     # cluster novo, tudo
ansible-playbook site.yml -e acao=instalar -e '{"componentes": ["kibana"]}' # so o Kibana
ansible-playbook site.yml -e acao=validar
```

Reexecutar é seguro (idempotente). Em cluster existente os nós reiniciam **um por vez** e só se algo mudou.
`es_bootstrap_allowed: true` só na **primeira** execução do cluster.

## 5. Discos

Você declara em `group_vars/` apenas **tamanho e quantidade** por volume (`storage_volumes`). Em cada servidor:

1. **Achar** os *discos crus* (precheck): disco inteiro, sem partição, sem volume e sem assinatura (`blkid` vazio). O `vg00` e os discos do sistema nunca entram.
2. **Conferir** (precheck): nº de discos crus **igual** ao pedido pelos volumes ainda não montados, e discos do tamanho certo (tolerância 3%).
   Sobrou ou faltou disco → para e **nada é formatado** em nenhum servidor.
3. **Criar** cada volume (infra, `volume.yml`): `lvg`, `lvol`, `filesystem` (xfs) e `mount`, um VG próprio por volume.

`acao=precheck` mostra o plano sem formatar nada. Pontos já montados são ignorados. 
Servidores sem `storage_volumes` (os `integration`) ficam fora do plano.

## 6. Fleet

- Os 2 servidores `integration` são os **Fleet Servers** (porta 8220). Os certificados deles são emitidos pelo projeto (CA http interna).
- **F5 é opcional.** Sem F5, os agentes recebem as 2 URLs e fazem failover. Com F5: VIP na 8220 em *TCP/SSL passthrough*,
  e `fleet_public_name` em `group_vars/all.yml` antes de instalar `elasticsearch` e `fleet`.
- O **service token** de cada Fleet Server é criado pelo playbook (não é o *enrollment token*, que você gera no Kibana para os agentes comuns).
- A licença Enterprise não bloqueia nada: o Fleet funciona na Basic. O Kibana precisa alcançar `epr.elastic.co`.

## 7. F5 e certificados

- Os certificados **da empresa ficam só no F5**; os servidores usam **CAs internas** (transporte e http). VIP Kibana `10.29.177.75` → 3 Kibana (5601, HTTPS);
  VIP Fleet `10.29.177.77` → 2 Fleet (8220, HTTPS);
  VIP Elasticsearch `10.29.177.76` → nós hot (9200, HTTPS).
- Para o F5 validar o backend, a CA http pública está no primeiro master em `/root/elastic-ca/ca_http/ca/ca.crt`.
  **Faça backup seguro de `/root/elastic-ca`** (contém as chaves das CAs).
- Servidor novo depois: inclua no `inventory.yml`, apague no primeiro master o `.zip` do conjunto dele em `/root/elastic-ca` e rode `instalar` com o componente certo.

## 8. Se algo falhar

| Sintoma | Causa provável |
|---------|----------------|
| `disco(s) cru(s) encontrado(s)...` (precheck) | discos diferentes do `storage_volumes`; veja o debug "Mostrar o plano de discos" |
| `Permission denied` / `kex_exchange_identification` ao conectar | chave não autorizada no root dos servidores, ou o `sshd` do bastion bloqueia redirecionamento |
| `Cluster NOVO detectado` | faltou `-e es_bootstrap_allowed=true` na 1ª instalação |
| `X de 3 masters tem a marca` | estado inconsistente: confira `/etc/elasticsearch/.cluster_uuid` nos 3 masters |
| espera "cluster green" por muito tempo | `journalctl -u elasticsearch` no nó; DNS e portas 9200/9300 entre os nós |
| Kibana não fica *available* | `journalctl -u kibana`; confira a senha do `kibana_system` |
| Fleet Server não fica HEALTHY | `elastic-agent status` e `journalctl -u elastic-agent`; acesso do Kibana ao registry |

## 9. Pontos a conferir na primeira execução

Dependem do comportamento real das ferramentas: a estrutura do `.zip` do `elasticsearch-certutil`, as chamadas de Fleet pela API do Kibana,
as opções do `elastic-agent install` e o `kibana-keystore add --stdin --force`. Se algum falhar, a mensagem do Ansible aponta a tarefa exata.

# ROLE infra (so na acao instalar): 1) DISCOS = LVM + XFS + fstab, um volume por vez (volume.yml); 2) SISTEMA = pacotes, chrony,
# kernel, swap, THP e limites. O plano de discos vem do role precheck. Idempotente; nao mexe em firewalld/SELinux.

# ------------------------------- 1) DISCOS ---------------------------------
- name: O plano de discos vem do role precheck (ele precisa ter rodado antes)
  ansible.builtin.assert:
    that: volumes_pendentes is defined
    fail_msg: "Sem o plano de discos. Use acao=instalar (ela roda o precheck antes)."
    quiet: true
  when: storage_volumes | length > 0

- name: Garantir as ferramentas de LVM e XFS
  ansible.builtin.dnf:
    name: [lvm2, xfsprogs]
    state: present
  when: volumes_pendentes | default([]) | length > 0

- name: Criar cada volume (passos em volume.yml)
  ansible.builtin.include_tasks: volume.yml
  loop: "{{ volumes_pendentes | default([]) }}"
  loop_control:
    label: "{{ item.mount }}"

# ------------------------------- 2) SISTEMA --------------------------------
- name: Instalar pacotes base
  ansible.builtin.dnf:
    name: [chrony, openssl, unzip, python3-dnf-plugin-versionlock]
    state: present

- name: Chrony - desativar as outras fontes de tempo (pool e server que nao sejam o NTP da empresa)
  ansible.builtin.replace:
    path: /etc/chrony.conf
    regexp: '^((?:pool|server) (?!{{ ntp_server | regex_escape }} ).*)$'
    replace: '# desativado-por-ansible: \1'
  register: chrony_pool

- name: Chrony - servidor NTP da empresa
  ansible.builtin.lineinfile:
    path: /etc/chrony.conf
    regexp: '^server {{ ntp_server | regex_escape }} '
    line: "server {{ ntp_server }} iburst"
  register: chrony_server

- name: Garantir chronyd habilitado e ativo (cluster exige relogios sincronizados)
  ansible.builtin.systemd_service:
    name: chronyd
    state: "{{ 'restarted' if (chrony_pool is changed or chrony_server is changed) else 'started' }}"
    enabled: true

- name: Acertar o relogio agora (so se o chrony foi reconfigurado)
  ansible.builtin.command: chronyc makestep
  when: chrony_pool is changed or chrony_server is changed
  changed_when: true

# ----------------------------- somente nos Elasticsearch ---------------------
- name: Ajustes do sistema exigidos pelo Elasticsearch
  when: inventory_hostname in groups['elasticsearch']
  block:
    - name: Parâmetros de kernel (max_map_count, swappiness, tcp_retries2)
      ansible.builtin.copy:
        dest: /etc/sysctl.d/elasticsearch.conf
        content: |
          vm.max_map_count = 1048576
          vm.swappiness = 1
          net.ipv4.tcp_retries2 = 5
        owner: root
        group: root
        mode: "0644"
      register: sysctl_arquivo

    - name: Aplicar os parâmetros de kernel agora
      ansible.builtin.command: sysctl -p /etc/sysctl.d/90-elasticsearch.conf
      #when: sysctl_arquivo is changed
      changed_when: true

    - name: Desligar o swap agora
      ansible.builtin.command: swapoff -a
      when: ansible_facts.swaptotal_mb | int > 0
      changed_when: true

    - name: Comentar as linhas de swap do /etc/fstab (gera backup)
      ansible.builtin.replace:
        path: /etc/fstab
        regexp: '^([^#\s]\S*\s+\S+\s+swap\s+.*)$'
        replace: '# desativado-por-ansible: \1'
        backup: true

    - name: Unidade systemd que fixa Transparent Huge Pages em "madvise" a cada boot
      ansible.builtin.copy:
        dest: /etc/systemd/system/elastic-thp.service
        content: |
          [Unit]
          Description=Transparent Huge Pages = madvise (requisito do Elasticsearch)
          DefaultDependencies=no
          After=sysinit.target local-fs.target
          Before=elasticsearch.service

          [Service]
          Type=oneshot
          RemainAfterExit=yes
          ExecStart=/bin/sh -c 'echo madvise > /sys/kernel/mm/transparent_hugepage/enabled'
          ExecStart=/bin/sh -c 'echo madvise > /sys/kernel/mm/transparent_hugepage/defrag'

          [Install]
          WantedBy=basic.target
        owner: root
        group: root
        mode: "0644"
      register: thp_unidade

    - name: Pasta de ajustes do serviço elasticsearch
      ansible.builtin.file:
        path: /etc/systemd/system/elasticsearch.service.d
        state: directory
        owner: root
        group: root
        mode: "0755"

    - name: Limites do serviço (memlock ilimitado é exigido por bootstrap.memory_lock)
      ansible.builtin.copy:
        dest: /etc/systemd/system/elasticsearch.service.d/override.conf
        content: |
          [Unit]
          RequiresMountsFor=/var/lib/elasticsearch /var/log/elasticsearch

          [Service]
          LimitMEMLOCK=infinity
          LimitNOFILE=65535
          LimitNPROC=4096
        owner: root
        group: root
        mode: "0644"
      register: limites

    - name: Recarregar o systemd se alguma unidade mudou
      ansible.builtin.systemd_service:
        daemon_reload: true
      when: thp_unidade is changed or limites is changed

    - name: Ligar a unidade de THP
      ansible.builtin.systemd_service:
        name: elastic-thp.service
        enabled: true
        state: started

    - name: Ler o estado EFETIVO do sistema (não só os arquivos)
      ansible.builtin.shell: |
        echo "max_map_count=$(sysctl -n vm.max_map_count)"
        echo "swappiness=$(sysctl -n vm.swappiness)"
        echo "swap_kb=$(awk '/SwapTotal/{print $2}' /proc/meminfo)"
        echo "thp=$(sed -n 's/.*\[\(.*\)\].*/\1/p' /sys/kernel/mm/transparent_hugepage/enabled)"
      args:
        executable: /bin/bash
      register: efetivo
      changed_when: false
      check_mode: false

    - name: Conferir o estado efetivo
      vars:
        e: "{{ dict(efetivo.stdout_lines | map('split', '=', 1)) }}"
      ansible.builtin.assert:
        that:
          - e.max_map_count | int >= 1048576
          - e.swappiness | int == 1
          - e.swap_kb | int == 0
          - e.thp == 'madvise'
        fail_msg: "Estado do SO divergente em {{ inventory_hostname }}: {{ e }}"
        quiet: true
      when: not ansible_check_mode

# FILE: ./roles/infra/tasks/volume.yml
################################################################
---
# infra / volume: cria UM volume (loop do main.yml). item = {name, vg, lv, mount, size_gb, count}
# lvg = pvcreate + vgcreate | lvol = lvcreate -l 100%FREE | filesystem = mkfs.xfs (nunca sobrescreve) | mount = fstab + mount
- name: "{{ item.mount }}: escolher os discos (tamanho certo, os primeiros da lista)"
  ansible.builtin.set_fact:
    discos_do_volume: >-
      {{ (discos_livres
          | selectattr('gb', 'ge', item.size_gb * 0.97)
          | selectattr('gb', 'le', item.size_gb * 1.03)
          | map(attribute='path') | list)[:item.count | int] }}

- name: "{{ item.mount }}: criar o VG {{ item.vg }} com esses discos (pvcreate + vgcreate)"
  community.general.lvg:
    vg: "{{ item.vg }}"
    pvs: "{{ discos_do_volume }}"
    state: present

    lv: "{{ item.lv }}"
    size: 100%FREE
    shrink: false

- name: "{{ item.mount }}: criar o filesystem XFS (mkfs.xfs)"

    state: directory

  changed_when: false
  when: ansible_facts.selinux.status | default('disabled') == 'enabled'

- name: "{{ item.mount }}: tirar esses discos da lista de livres"

# ---- CERTIFICADOS (es_nos, kibana, fleet_servers) ----
# Parte 1 (1o master): cria as 2 CAs internas (transport e http) e emite todos os certificados (SAN = nome, nome curto, IP).
# Parte 2 (cada servidor): copia so os arquivos dele. Os certificados da empresa ficam so no F5.
- name: CERTIFICADOS - PARTE 1 (emitir; so no servidor da CA, uma vez)
  when: fase in ['es_nos', 'kibana', 'fleet_servers']
  delegate_to: "{{ ca_host }}"
  run_once: true
  vars:
    certutil: "{{ es_bin }}/elasticsearch-certutil"
    # grupos de servidores que recebem certificado, e nomes extras (VIPs do F5) no SAN
    conjuntos:
      - {nome: es,     grupo: elasticsearch, dns_extra: ["{{ es_public_name }}"]}
      - {nome: kibana, grupo: kibana,        dns_extra: ["{{ kibana_public_name }}"]}
      - {nome: fleet,  grupo: integration,   dns_extra: "{{ [fleet_public_name] if fleet_public_name | length > 0 else [] }}"}
    # o que emitir: nome do pacote, grupo de servidores, qual CA assina, formato (pem = crt+key, senao .p12)
    emissoes:
      - {nome: es_transport, conjunto: es,     ca: transport, pem: false}
      - {nome: es_http,      conjunto: es,     ca: http,      pem: false}
      - {nome: kibana_http,  conjunto: kibana, ca: http,      pem: false}
      - {nome: fleet_http,   conjunto: fleet,  ca: http,      pem: true}
  block:
    - name: Pasta das CAs (somente root)
      ansible.builtin.file:
        path: "{{ ca_dir }}"
        state: directory
        owner: root
        group: root
        mode: "0700"

    - name: Criar as duas CAs (validade 10 anos; chave protegida pela senha do vault)
      ansible.builtin.command:
        argv:
          - "{{ certutil }}"
          - ca
          - --silent
          - --pem
          - --days
          - "3650"
          - --pass
          - "{{ tls_ca_password }}"
          - --out
          - "{{ ca_dir }}/ca_{{ item }}.zip"
        creates: "{{ ca_dir }}/ca_{{ item }}.zip"
      loop: [transport, http]
      register: cas_certutil
      failed_when: false          # o erro do certutil aparece na conferencia abaixo (no_log esconderia)

      loop: "{{ cas_certutil.results }}"
      loop_control:
        label: "{{ item.item }}"

    - name: "Extrair as CAs (arquivos ca_http/ca/ca.crt e ca_http/ca/ca.key)"

        creates: "{{ ca_dir }}/ca_{{ item }}/ca/ca.crt"
      loop: [transport, http]

    - name: Listar os servidores de cada grupo (instances.yml do certutil)
      ansible.builtin.copy:
        dest: "{{ ca_dir }}/instancias_{{ item.nome }}.yml"
        owner: root
        group: root
        mode: "0600"
        content: |
          instances:
          {% for h in groups[item.grupo] %}
            - name: "{{ h.split('.')[0] }}"
              dns: {{ ([h, h.split('.')[0], 'localhost'] + item.dns_extra) | to_json }}

      loop: "{{ conjuntos }}"
      loop_control:
        label: "{{ item.nome }}"

    - name: Emitir os certificados (validade 3 anos)
      vars:
        base:
          - "{{ certutil }}"
          - cert
          - --silent
          - --days
          - "1095"
          - --ca-cert
          - "{{ ca_dir }}/ca_{{ item.ca }}/ca/ca.crt"
          - --ca-key
          - "{{ ca_dir }}/ca_{{ item.ca }}/ca/ca.key"
          - --ca-pass
          - "{{ tls_ca_password }}"
          - --in
          - "{{ ca_dir }}/instancias_{{ item.conjunto }}.yml"
          - --out
          - "{{ ca_dir }}/{{ item.nome }}.zip"
        # .p12 leva a senha tls_p12_password; PEM (Fleet Server) sai sem senha na chave

      ansible.builtin.command:
        argv: "{{ base + formato }}"
        creates: "{{ ca_dir }}/{{ item.nome }}.zip"
      loop: "{{ emissoes }}"
      loop_control:
        label: "{{ item.nome }}"
      register: emissao_certutil
      failed_when: false          # o erro do certutil aparece na conferencia abaixo (no_log esconderia)
      no_log: true

    - name: Conferir que o certutil emitiu os certificados (se falhou, mostra o erro dele)
      ansible.builtin.assert:
        that: item.rc | default(0) == 0
        fail_msg: "certutil cert ({{ item.item.nome }}) falhou: {{ item.stderr | default('') }} {{ item.stdout | default('') }}"
      loop: "{{ emissao_certutil.results }}"
      loop_control:
        label: "{{ item.item.nome }}"

    - name: Pasta dos certificados emitidos (o unzip -d não cria pastas intermediárias)

        path: "{{ ca_dir }}/emitidos"
        state: directory
        owner: root

        creates: "{{ ca_dir }}/emitidos/{{ item.nome }}"
      loop: "{{ emissoes }}"
      loop_control:
        label: "{{ item.nome }}"

    - name: Conferir que todos os arquivos esperados existem (CA, certificado e chave de cada servidor)
      # falha aqui, listando o que faltou e o que existe, e nao la na copia para os servidores

          {% for h in groups['kibana'] %}{% set c = h.split('.')[0] %}emitidos/kibana_http/{{ c }}/{{ c }}.p12 {% endfor %}
          {% for h in groups['integration'] %}{% set c = h.split('.')[0] %}emitidos/fleet_http/{{ c }}/{{ c }}.crt emitidos/fleet_http/{{ c }}/{{ c }}.key {% endfor %}
      ansible.builtin.shell: |
        cd {{ ca_dir }}
        falta=0
        for f in {{ esperados }}; do [ -f "$f" ] || { echo "FALTA $f"; falta=1; }; done
        if [ "$falta" = 1 ]; then echo "--- o que existe em {{ ca_dir }} ---"; find . -maxdepth 4 -type f | sort | head -80; fi
      register: conferencia_cert
      changed_when: false
      failed_when: "'FALTA' in conferencia_cert.stdout"

# ---- FASE fleet_servers: instala o Fleet Server (Elastic Agent, porta 8220) nos servidores integration ----
# Um service token por servidor (nao e o enrollment token). Agente ja instalado = servidor pulado (o token nao e recriado).
- name: FASE fleet_servers
  when: fase == 'fleet_servers'
  block:
    - name: Ver se o Elastic Agent já está instalado
      ansible.builtin.stat:
        path: /opt/Elastic/Agent/elastic-agent
      register: agente

    - name: Instalar o Fleet Server neste servidor
      when: not agente.stat.exists
      vars:
        curto: "{{ inventory_hostname.split('.')[0] }}"
        pacote_agente: "elastic-agent-{{ elastic_version }}-linux-x86_64"
        url_pacote: "https://artifacts.elastic.co/downloads/beats/elastic-agent/{{ pacote_agente }}.tar.gz"
        token_url: "{{ es_api_url }}/_security/service/elastic/fleet-server/credential/token/fleet-{{ curto }}"
        hot_url: "https://{{ hostvars[groups['es_hot'][0]].ansible_host }}:9200"
        proxy_env: "{{ {'https_proxy': elastic_repo_proxy} if elastic_repo_proxy | length > 0 else {} }}"
      block:
        - name: Baixar o pacote do Elastic Agent (confere SHA-512)
          ansible.builtin.get_url:
            url: "{{ url_pacote }}"
            checksum: "sha512:{{ url_pacote }}.sha512"
            dest: "/root/{{ pacote_agente }}.tar.gz"
            mode: "0600"
          environment: "{{ proxy_env }}"

        - name: Extrair o pacote
          ansible.builtin.unarchive:
            src: "/root/{{ pacote_agente }}.tar.gz"
            dest: /root
            remote_src: true
            creates: "/root/{{ pacote_agente }}/elastic-agent"

        - name: Criar o service token deste Fleet Server (apaga um antigo de mesmo nome, se houver)
          # Seguro: so chega aqui se o agente NAO esta instalado, entao nenhum token em uso e revogado.
          delegate_to: "{{ es_api_host }}"
          module_defaults:
            ansible.builtin.uri:
              url_username: elastic
              url_password: "{{ es_elastic_password }}"
              force_basic_auth: true
              ca_path: "{{ es_tls_dir }}/http_ca.crt"
              return_content: true
          block:
            - name: Apagar token antigo (404 = não existia, tudo bem)
              ansible.builtin.uri:
                url: "{{ token_url }}"
                method: DELETE
                status_code: [200, 404]
              no_log: true

            - name: Criar o token
              ansible.builtin.uri:
                url: "{{ token_url }}"
                method: POST
                status_code: 200
              register: token
              no_log: true

        - name: Instalar o Elastic Agent como Fleet Server
          # --url: endereco que este Fleet Server anuncia; --fleet-server-es: Elasticsearch e CA; token/policy: criados acima; cert/key: porta 8220
          ansible.builtin.command:
            argv:
              - "/root/{{ pacote_agente }}/elastic-agent"
              - install
              - --non-interactive
              - "--url=https://{{ ansible_host }}:{{ fleet_port }}"
              - "--fleet-server-es={{ hot_url }}"
              - "--fleet-server-es-ca=/etc/fleet-server-tls/http_ca.crt"
              - "--fleet-server-service-token={{ token.json.token.value }}"
              - "--fleet-server-policy=fleet-server-policy"
              - "--fleet-server-port={{ fleet_port }}"
              - "--fleet-server-cert=/etc/fleet-server-tls/fleet.crt"
              - "--fleet-server-cert-key=/etc/fleet-server-tls/fleet.key"
              - "--certificate-authorities=/etc/fleet-server-tls/http_ca.crt"
            creates: /opt/Elastic/Agent/elastic-agent
          no_log: true

        - name: Apagar o instalador (o agente já está em /opt/Elastic/Agent)
          ansible.builtin.file:
            path: "{{ item }}"
            state: absent
          loop:
            - "/root/{{ pacote_agente }}"
            - "/root/{{ pacote_agente }}.tar.gz"

    - name: Esperar o Fleet Server responder na porta do Fleet
      ansible.builtin.uri:
        url: "https://{{ ansible_host }}:{{ fleet_port }}/api/status"
        ca_path: /etc/fleet-server-tls/http_ca.crt
        return_content: true
        status_code: [-1, 200, 503]
      register: status_fleet
      until: status_fleet.status == 200 and status_fleet.json.status == 'HEALTHY'
      retries: 30
      delay: 10
      changed_when: false

    success_msg: "Precheck aprovado em {{ inventory_hostname }}"

# 4) PLANO DE DISCOS (somente leitura): ACHAR os discos crus e CONFERIR quantidade/tamanho com o group_vars/; se nao bater, PARA.
#    Disco cru = inteiro, sem particao, sem volume e sem assinatura (blkid vazio): vg00 e discos do sistema nunca entram.
#    Servidores sem storage_volumes (ex.: integration) nao participam.
- name: Plano de discos
  when: storage_volumes | length > 0
  block:
    - name: Achar os discos crus (somente leitura)
      # Imprime uma linha JSON por disco:  {"path": "/dev/disk/by-path/...", "gb": 1024.0}
      # O by-path e usado porque o nome (sdb, sdc) pode mudar entre reboots.
      ansible.builtin.shell: |
        for d in $(lsblk -dn -o NAME,TYPE | awk '$2=="disk"{print $1}'); do
          [ "$(lsblk -n -o NAME /dev/$d | wc -l)" -eq 1 ] || continue      # tem particao ou volume em cima: nao e cru
          blkid -p /dev/$d >/dev/null 2>&1; [ $? -eq 2 ] || continue       # tem assinatura (rc 2 = nada encontrado): nao e cru
          path=$(for l in /dev/disk/by-path/*; do [ "$(readlink -f $l)" = "/dev/$d" ] && echo $l; done | grep -v -- '-part' | head -1)
          [ -n "$path" ] || continue
          gb=$(lsblk -dbn -o SIZE /dev/$d | awk '{printf "%.1f", $1/1073741824}')
          printf '{"path": "%s", "gb": %s}\n' "$path" "$gb"
        done | sort
      args:
        executable: /bin/bash
      register: achados
      changed_when: false
      check_mode: false

    - name: Montar as listas de trabalho
      ansible.builtin.set_fact:
        # discos crus ainda sem dono (vai diminuindo a cada volume criado)
        discos_livres: "{{ achados.stdout_lines | map('from_json') | list }}"
        # volumes do group_vars que ainda NAO estao montados (reexecucao: o que ja existe e ignorado)
        volumes_pendentes: "{{ storage_volumes | rejectattr('mount', 'in', ansible_facts.mounts | map(attribute='mount') | list) | list }}"

    - name: Mostrar o plano de discos
      ansible.builtin.debug:
        msg:
          discos_crus_encontrados: "{{ discos_livres | map(attribute='gb') | list }}"
          volumes_a_criar: "{{ volumes_pendentes | map(attribute='mount') | list }}"

    - name: Parar se a quantidade de discos crus nao bater com o group_vars
      # Regra: discos crus encontrados == discos pedidos pelos volumes pendentes (sobrou ou faltou = para).
      ansible.builtin.assert:
        that: discos_livres | length == volumes_pendentes | map(attribute='count') | map('int') | sum
        fail_msg: >-
          {{ inventory_hostname }}: {{ discos_livres | length }} disco(s) cru(s) encontrado(s) ({{ discos_livres | map(attribute='gb') | list }} GB),
          mas o group_vars pede {{ volumes_pendentes | map(attribute='count') | map('int') | sum }}. Nada foi formatado.
        quiet: true

    - name: Parar se faltar disco do tamanho certo para algum volume (tolerancia de 3%)
      vars:
        do_tamanho: "{{ discos_livres | selectattr('gb', 'ge', item.size_gb * 0.97) | selectattr('gb', 'le', item.size_gb * 1.03) | list }}"
      ansible.builtin.assert:
        that: do_tamanho | length >= item.count | int
        fail_msg: "{{ inventory_hostname }}: {{ item.mount }} pede {{ item.count }} disco(s) de {{ item.size_gb }} GB, so ha {{ do_tamanho | length }}. Nada foi formatado."
        quiet: true
      loop: "{{ volumes_pendentes }}"
      loop_control:
        label: "{{ item.mount }}"

CONTEXTO

Estou desenvolvendo uma automação Ansible para o Jira.

O objetivo é localizar solicitações de renovação de certificados e posteriormente atualizar alertas de expiração de certificados no Zabbix.

Já consegui identificar os chamados corretamente.

A automação atualmente faz:

```yaml
- name: Buscar atualizações de alerta
  ansible.builtin.uri:
    url: "{{ jira_base_url }}/rest/api/3/search/jql"
    method: POST
    force_basic_auth: true
    user: "{{ jira_user }}"
    password: "{{ jira_password }}"
    headers:
      Accept: application/json
      Content-Type: application/json
    body_format: json
    body:
      jql: >-
        project = {{ projeto_jira }}
        AND summary ~ "\"Atualização de alerta\""
        AND statusCategory != Done
      maxResults: 1000
      fields:
        - summary
        - description
        - customfield_10238
  register: jira_search

- name: Selecionar tickets de atualização de alerta
  ansible.builtin.set_fact:
    tickets_certificados: >-
      {{
        jira_search.json.issues
        | selectattr('fields.summary', 'equalto', 'Atualização de alerta')
        | list
      }}

OBJETIVO

Preciso transformar essa estrutura ADF em uma variável Ansible simples para ser consumida posteriormente por uma automação Zabbix.

Resultado esperado:

YAML
certificados_para_atualizar:
 
- host: icops.claro.com.br
validade: "19/03/2027"
 
- host: clarocluberest.claro.com.br
validade: "23/03/2027"
 
- host: hmlg.institutoclaro.org.br
validade: "23/03/2027"

REQUISITOS IMPORTANTES

Não criar role nova.
Não criar plugin custom.
Não criar filtro custom.
Não criar script Python externo.
Não criar include_tasks.
Não criar arquivos temporários.
Não criar uma solução exageradamente complexa.
Priorizar simplicidade e legibilidade.
O código deve ficar fácil para qualquer operador Ansible entender.
Evitar Jinja excessivamente complexo.
Evitar blocos enormes difíceis de manter.
Se possível, quebrar em poucas tasks claras e objetivas.

RESULTADO FINAL ESPERADO

No final quero apenas uma variável:

YAML
certificados_para_atualizar

para ser utilizada posteriormente assim:

YAML
- name: Atualizar certificados no Zabbix
loop: "{{ certificados_para_atualizar }}"

consumindo:

YAML
item.host
item.validade

PEDIDO

Com base no ADF real fornecido acima, forneça a forma mais simples, legível, funcional e de fácil manutenção para montar a variável:

YAML
certificados_para_atualizar

em Ansible.
